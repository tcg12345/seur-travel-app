# Seur identity

The flight ribbon combines an abstract soaring wing with the curve of an S. Ivory on deep forest green brings the same mark to the home screen, welcome, Discover, workspace, concierge and Reserve preview. The wordmark uses SEUR in the app's existing native typography.

## Assets

- `Seur-logo-master.png`: original generated square artwork, 1254 × 1254 pixels.
- `../Aurum/Assets.xcassets/AppIcon.appiconset/AppIcon.png`: opaque 1024 × 1024 app icon, mechanically downsampled for Apple's asset catalog. iOS applies its own icon shape.
- `../Aurum/Assets.xcassets/SeurLogo.imageset/SeurLogo.png`: original artwork shared by native logo badges. The SwiftUI `SeurLogo` component sizes it consistently.

Generated using the built-in image_gen tool, not the API/CLI fallback. No external brand assets or airplane silhouette are used. The internal Xcode scheme, bundle identifier, stored library paths, preference keys and Keychain service remain compatible with existing installs; both display name and bundle name are Seur.

## Final generation prompt

Use case: logo-brand. Create ONE finished, original app icon for Seur, a premium modern iOS luxury travel app. A distinctive abstract soaring wing / wind-ribbon symbol that subtly suggests an S and an ascending journey, without depicting an airplane. Elegant swept curves with precise tapered ends, balanced negative space, exceptionally simple and memorable silhouette readable at tiny icon sizes. Think quiet sophistication, movement and freedom. Center the single warm ivory symbol (#F5EFE3) on a completely flat deep forest-green background (#213C35). Symbol occupies about 62 percent of the square, ample even clear space around it. Pure flat vector-like design, crisp edges, no textures, no metallic effects, no gradients, no shadow, no border. Full-bleed 1024 by 1024 square artwork with opaque background all the way to the edges; NO rounded corners baked into artwork. No text, no letters written out, no wordmark, no mockup, no airplane silhouette, no globe, no compass, no extra decoration. This image itself will be the shipping Apple app icon.
