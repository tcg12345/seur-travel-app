# Seur identity

The flight ribbon combines an abstract soaring wing with the curve of an S. A bronze symbol on warm ivory appears on the home screen and in the shared logo throughout the app. Use bronze, ivory and warm charcoal for Seur branding; do not use forest green.

- `Seur-logo-master.png`: full-resolution recolored source artwork.
- `../Aurum/Assets.xcassets/AppIcon.appiconset/AppIcon.png`: opaque 1024 × 1024 shipping app icon.
- `../Aurum/Assets.xcassets/SeurLogo.imageset/SeurLogo.png`: matching shared native logo.
- Native colors are defined in `DesignSystem.swift`; `brandInk` and `brandBronze` support surfaces with light foreground content.

## Recolor direction

Preserve the existing wing/S ribbon silhouette and placement. Replace the background with warm ivory #F8F6F1 and the symbol with bronze #8C6338. No green, added shapes, text, borders or baked-in rounded corners. The original icon was supplied as the reference for the image edit.
